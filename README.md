# simulation
## Travaux de simulation

Dans ce dépôt, je partage une partie de mes travaux liés à la simulation numérique, réalisés principalement avec **Ansys** et **Abaqus**. Ces projets incluent des études de mécanique des structures, de modélisation numérique et d'analyse par éléments finis.

Pour des raisons de confidentialité, certains projets ou certaines parties de ces travaux ne peuvent pas être rendus entièrement publics. Par conséquent, seuls les éléments qui peuvent être partagés librement sont disponibles dans ce dépôt.

L'objectif de ce repository est de présenter une partie de mes compétences en simulation numérique, modélisation mécanique et analyse scientifique.

Merci pour votre compréhension.
